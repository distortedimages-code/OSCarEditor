nouveautés

Les dernières versions

0.5.0
dernière version

0.5.0 : OXIde. Le plugin s'appelle maintenant OXIde, avec un nouveau logo. La mise à jour depuis le plugin met OXIde à la place d'OSCar Editor et retire les anciennes copies ; tes réglages, banques, voix et sauvegardes passent dans Documents › OXIde. Si les deux noms se retrouvent côte à côte (après une installation à la main depuis l'image disque, par exemple), le plugin propose de mettre les anciens à la corbeille. Dans Logic, OXIde est rangé sous OSCarTools, et les projets faits avec OSCar Editor s'ouvrent comme avant.

Une page Voix qui se lit comme un schéma. La fenêtre est plus haute (1400 × 900 à 100 %). À l'étage du haut, le son : les molettes, puis oscillateurs → mix → filtre. En bas, ce qui le façonne : LFO, glide, triggering, arpégiateur, horloge, et les deux enveloppes côte à côte, celle de l'ampli en dernier. Des lignes imprimées montrent le chemin : le son en orange le long des titres, les modulations vers ENV AMOUNT, LFO AMOUNT et la hauteur des oscillateurs, et le DELAY de l'enveloppe du filtre, de Sustain à Release. Sur chaque rangée, tous les noms et tous les afficheurs de valeur sont à la même hauteur.

- Les formes d'onde sont des potards avec les positions de la façade (N, rampe, carré, impulsion, PWM, off) ; les formes −3 à −12 affichent leur numéro sous le potard. - Function, le type de glide et le type de filtre sont des potards à six positions, comme sur la façade : les trois dernières, sous un arc, sont HOLD, FIX et NO TRACK. - L'octave du clavier a ses cinq LED. Les enveloppes repassent en tirettes, quatre côte à côte pour chacune. - La colonne ARP réunit Function, Direction et Mode ; la colonne CLOCK réunit Sync, la division d'horloge externe et le tempo.

Les autres pages profitent de la hauteur : un aperçu de morphing plus grand, les commandes du générateur au milieu de leurs colonnes, un mode d'emploi plus haut dans Réglages.

Aussi nouveau depuis la 0.3.0

- Morphing A ↔ B : une page avec deux voix et un crossfader façon Octatrack. Les potards glissent de A vers B, les sélecteurs basculent à mi-course ; le lissage transforme un geste brusque en glissement. Avec Live CC, l'OSCar suit en direct, le plugin n'envoyant que les CC qui ont changé. Garde le mélange ou annule-le d'un coup ; le fader s'automatise dans Logic (Morph A-B). - Init : un son de départ neutre pour construire une voix à partir de zéro (page Banques, et en haut du menu des voix). - Les mémoires dans l'ordre du clavier : -12 … -1, puis 1 … 24, comme sur les touches de l'OSCar. - Les mots et les graduations de la façade : OSC 1 WAVEFORM, DE TUNE, OSC BALANCE, Q, SEPARATION, PITCH MOD, TRIGGERING, GATE TIME… avec − / 0 / + sur les potards bipolaires. Ils restent en anglais en mode français, comme sur le synthé. - Une façade qui a vécu : l'encre est légèrement usée par endroits ; les commandes restent intactes.

Une fois installé, le plugin te prévient lui-même quand une version sort : un bouton Mise à jour apparaît en haut de sa fenêtre. Un clic, puis tu relances Logic.

installation

Installer et brancher, pas à pas

Compte un quart d'heure la première fois. Les versions suivantes s'installent depuis le plugin, sans refaire ces étapes.

  1. 1

    Ouvrir l'image disque et glisser les fichiers

    Double-clique sur OXIde-mac.dmg. Dans la fenêtre, glisse chaque fichier sur le dossier en face. macOS peut te demander ton mot de passe.

    Logic Pro n'utilise que l'AU ; le VST3 sert aux autres logiciels, l'application marche sans DAW. Déjà installé ? Pas besoin du DMG : le plugin se met à jour lui-même.

  2. 2

    Débloquer le plugin, une seule fois

    Le plugin n'est pas notarisé par Apple : tant qu'il n'est pas débloqué, macOS empêche Logic de le charger. Ouvre Terminal (⌘ Espace, tape « Terminal », Entrée), colle ce texte et appuie sur Entrée. Terminal demande le mot de passe de ta session : rien ne s'affiche pendant la frappe, c'est normal.

    La dernière ligne doit dire « AU VALIDATION SUCCEEDED. » : Logic Pro peut alors charger le plugin. « No such file » pour un format que tu n'as pas installé est normal. Le début de la commande retire les copies à l'ancien nom (OSCar Editor) s'il en reste : c'est le même plugin, et deux copies embrouillent Logic. Les mises à jour faites depuis le plugin n'ont pas besoin de ce déblocage.

    Terminal
    sudo rm -rf \
  "/Library/Audio/Plug-Ins/Components/OSCar Editor.component" \
  "/Library/Audio/Plug-Ins/VST3/OSCar Editor.vst3" \
  "/Applications/OSCar Editor.app"; \
sudo xattr -dr com.apple.quarantine \
  "/Library/Audio/Plug-Ins/Components/OXIde.component" \
  "/Library/Audio/Plug-Ins/VST3/OXIde.vst3" \
  "/Applications/OXIde.app"; \
killall -9 AudioComponentRegistrar 2>/dev/null; \
auval -v aumu Oscr Otls | tail -n 1
  3. 3

    L'ouvrir dans Logic Pro

    Relance Logic Pro : il vérifie les nouveaux plugins au démarrage. Crée une piste d'instrument logiciel, clique sur le slot d'instrument et choisis OXIde dans les instruments AU, rubrique OSCarTools.

    Il n'apparaît pas ? Logic Pro › Réglages › Gestionnaire de module : sélectionne OXIde, puis « Réinitialiser et réanalyser la sélection ». Le plugin ne produit aucun son : il parle directement à l'OSCar par ton interface MIDI.

  4. 4

    Brancher l'OSCar et choisir les ports

    Un câble va toujours d'un OUT vers un IN. Puis, page Réglages du plugin : Sortie = la sortie de l'interface où arrive le câble 1, Entrée = l'entrée où arrive le câble 2, canal 1 sauf si ton OSCar est réglé autrement.

    Avec un câble USB-MIDI tout-en-un, les fiches IN et OUT sont parfois étiquetées à l'envers : si rien ne passe, inverse-les. Le plugin retient tes ports.

  5. 5

    Deux réglages sur l'OSCar

    Program change, pour que l'OSCar passe sur la voix que tu cliques dans le plugin : maintiens SPACE (à gauche du clavier) et appuie sur la touche −9. La LED −9 s'allume.

    Patch CC dump, pour que le plugin suive les voix choisies sur l'OSCar : maintiens TUNE/TRANSPOSE et appuie sur la touche « Enable patch CC dump », la dernière touche noire de l'octave du milieu. Le voyant CC DUMP du plugin s'allume au prochain changement de voix.

    Si l'OSCar ne suit plus après avoir été éteint, refais ces deux réglages.

    SPACEmaintenir+touche −9
    TUNE/TRANSPOSEmaintenir+Enable patch CC dump
  6. 6

    Récupérer tes voix, avant tout le reste

    Plugin ouvert, sur l'OSCar : maintiens INSERT, appuie sur VOICE, puis sur SPACE. L'OSCar envoie ses 36 voix en moins d'une seconde et le bas de la fenêtre affiche « Voix reçues (36) ».

    Une copie part automatiquement dans Documents › OXIde › Backups. C'est ta sauvegarde : tout se recharge depuis la page Banques.

    Rien ne s'affiche ? L'entrée MIDI choisie à l'étape 4 n'est pas la bonne, ou le câble 2 est mal branché.

    INSERTmaintenir+VOICEpuisSPACE

Bon à savoir

Récupérer un son fait sur l'OSCar

Le plugin ne reçoit que ce qui est enregistré dans l'OSCar, pas le son en cours de réglage. Pour garder un son créé directement sur la machine :

  1. Sur l'OSCar, enregistre ton son dans une mémoire que tu peux écraser (STORE, comme d'habitude).
  2. Maintiens INSERT, appuie sur VOICE, puis sur SPACE : le plugin reçoit les 36 voix avec leurs valeurs exactes et affiche « Voix reçues (36) ».
  3. Dans le plugin, clique sur le numéro de cette mémoire : ton son s'affiche avec tous ses réglages.
  4. Page Banques : « Renommer » pour lui donner un nom, puis « Sauver voix… » (dossier Voices) ou « Enregistrer la banque… » pour garder les 36 voix.

Avec le patch CC dump, le plugin affiche déjà le son dès que tu choisis la mémoire sur l'OSCar, mais les potards sont à un cran près. Pour garder un son, préfère l'envoi INSERT, VOICE, SPACE.

Le son change en direct

Avec Live CC allumé, chaque potard part tout de suite vers l'OSCar. Ce n'est enregistré dans sa mémoire qu'avec « Envoyer au synthé », qui écrit les 36 voix d'un coup.

Le plugin suit l'OSCar

Choisis une voix sur l'OSCar : le plugin l'affiche telle qu'elle joue, mode Duo ou Arp compris. Il faut le patch CC dump (étape 5).

Essayer sans risque

Le Générateur joue chaque essai sur l'OSCar sans toucher à sa mémoire. « Retour à l'original » annule, « Garder » met le son dans la voix.

Arpège calé sur Logic

Page Voix, bloc horloge midi : tourne Sync sur MIDI et choisis une Division (1/16, 1/8T…). Puis, au choix, « Envoyer l'horloge MIDI du DAW à l'OSCar » dans Réglages, ou l'horloge de Logic (Fichier › Réglages du projet › Synchronisation › MIDI, Destination = le port de l'OSCar, case Horloge). Pas les deux.

Jouer l'OSCar depuis Logic

Sélectionne la piste OXIde et allume MIDI Thru (en bas de la fenêtre) : ton clavier maître et les régions MIDI de la piste jouent l'OSCar. Laisse-le éteint si tu joues déjà l'OSCar avec le module External Instrument de Logic.

Rien ne se perd

Chaque réception et chaque envoi est sauvegardé. « Sauver voix… » range une voix dans Voices, « Enregistrer la banque… » une banque dans Banks. Un double-clic les recharge.

Gare aux touches rouges

Sur la page Raccourcis Tauntek, les touches en rouge (sons d'usine, B, C, zones de sauvegarde) remplacent les 36 voix de l'OSCar. Enregistre une banque avant.

Rien à router dans Logic

Dans Logic, un instrument AU ne peut pas envoyer de MIDI vers une interface. OXIde parle donc à l'OSCar par ses propres ports MIDI, choisis dans Réglages.
