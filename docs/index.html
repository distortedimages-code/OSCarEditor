nouveautés

Les dernières versions

0.2.0
novembre 2026

Interface en français (English au choix dans Réglages). Les noms des réglages et des touches de l'OSCar restent ceux de la façade.

Nouveau look « Atelier » : façade d'instrument avec joues en bois, potards, faders d'enveloppe, voyants et afficheur orange. La fenêtre peut être agrandie ou réduite.

Rappel automatique : quand tu choisis une voix sur l'OSCar (avec le patch CC dump Tauntek activé), le plugin affiche exactement ce que joue l'OSCar, Duo/Arp compris.

Horloge MIDI : l'arpégiateur et le séquenceur peuvent suivre l'horloge MIDI (Sync), avec la division en clair (1/16, 1/8T…). Le plugin peut envoyer l'horloge du DAW à l'OSCar, avec Start / Stop.

Générateur de sons : Varier, Nouveau (basse, lead, pad, percussif, texture) et Croiser, avec verrous par section et historique. Les résultats jouent tout de suite sur l'OSCar, sans toucher à sa mémoire.

Page Banques : tes banques, tes voix et toutes les sauvegardes automatiques, rechargeables d'un double-clic. Les voix s'enregistrent directement dans le dossier Voices, les banques dans Banks. Le contenu de l'OSCar est aussi sauvegardé avant chaque envoi.

Page Raccourcis Tauntek : tous les raccourcis TUNE/TRANSPOSE sur un clavier, avec les touches dangereuses en rouge.

MIDI Thru : jouer l'OSCar depuis la piste du DAW (notes et pitch bend).

Mises à jour intégrées : le plugin signale les nouvelles versions et se met à jour lui-même sur Mac.

Une fois installé, le plugin te prévient lui-même quand une version sort : un bouton Mise à jour apparaît en haut de sa fenêtre. Un clic, puis tu relances le DAW.

installation

Installer et brancher, pas à pas

Compte un quart d'heure la première fois. Les versions suivantes s'installent depuis le plugin, sans refaire ces étapes.

  1. 1

    Télécharger

    Le bouton Télécharger pour Mac donne le fichier OSCar-Editor-mac.zip. Double-clique dessus s'il n'est pas déjà décompressé : tu obtiens trois fichiers.

    Tu peux n'installer que le format qu'utilise ton DAW. Live, Bitwig et Reaper lisent le VST3 ; Logic n'utilise que l'AU.

    OSCar-Editor-mac.zip
    AUOSCar Editor.component
    VST3OSCar Editor.vst3
    APPOSCar Editor.app
  2. 2

    Ranger chaque fichier à sa place

    Dans le Finder, menu Aller › Aller au dossier… (ou ⇧⌘G). Colle le chemin, appuie sur Entrée, puis glisse le fichier dans la fenêtre qui s'ouvre.

    Le dossier Library (Bibliothèque) est caché dans le Finder, mais « Aller au dossier » l'ouvre quand même. Si une ancienne version s'y trouve, remplace-la.

    AUOSCar Editor.component~/Library/Audio/Plug-Ins/Components
    VST3OSCar Editor.vst3~/Library/Audio/Plug-Ins/VST3
    APPOSCar Editor.app/Applications
  3. 3

    Débloquer le plugin, une seule fois

    Le plugin n'est pas notarisé par Apple : tant qu'il n'est pas débloqué, macOS empêche le DAW de le charger. Ouvre Terminal (Applications › Utilitaires), colle ces lignes et appuie sur Entrée.

    Si rien ne s'affiche, c'est bon. « no matches found » veut dire qu'un fichier n'est pas dans son dossier : refais l'étape 2 (ou ignore la ligne de l'application si tu ne l'as pas installée). Les mises à jour faites depuis le plugin n'ont pas besoin de ce déblocage.

    Terminal
    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/OSCar*
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/OSCar*
xattr -dr com.apple.quarantine /Applications/OSCar*
  4. 4

    L'ouvrir dans le DAW

    Relance le DAW et fais-lui rescanner les plugins. Dans Live : Réglages › Plug-ins, active les Audio Units ou les dossiers VST3 système, puis relance le scan. Glisse ensuite OSCar Editor sur une piste MIDI vide et ouvre sa fenêtre.

    Le plugin ne produit aucun son : il parle directement à l'OSCar par ton interface MIDI. Dans Logic, il est rangé dans les instruments AU, rubrique OSCarTools.

  5. 5

    Brancher l'OSCar et choisir les ports

    Un câble va toujours d'un OUT vers un IN. Puis, page Réglages du plugin : Sortie = la sortie de l'interface où arrive le câble 1, Entrée = l'entrée où arrive le câble 2, canal 1 sauf si ton OSCar est réglé autrement.

    Avec un câble USB-MIDI tout-en-un, les fiches IN et OUT sont parfois étiquetées à l'envers : si rien ne passe, inverse-les. Le plugin retient tes ports.

  6. 6

    Deux réglages sur l'OSCar

    Program change, pour que l'OSCar passe sur la voix que tu cliques dans le plugin : maintiens SPACE (à gauche du clavier) et appuie sur la touche −9. La LED −9 s'allume.

    Patch CC dump, pour que le plugin suive les voix choisies sur l'OSCar : maintiens TUNE/TRANSPOSE et appuie sur la touche « Enable patch CC dump », la dernière touche noire de l'octave du milieu. Le voyant CC DUMP du plugin s'allume au prochain changement de voix.

    Si l'OSCar ne suit plus après avoir été éteint, refais ces deux réglages.

    SPACEmaintenir+touche −9
    TUNE/TRANSPOSEmaintenir+Enable patch CC dump
  7. 7

    Récupérer tes voix, avant tout le reste

    Plugin ouvert, sur l'OSCar : maintiens INSERT, appuie sur VOICE, puis sur SPACE. L'OSCar envoie ses 36 voix en moins d'une seconde et le bas de la fenêtre affiche « Voix reçues (36) ».

    Une copie part automatiquement dans Documents › OSCar Editor › Backups. C'est ta sauvegarde : tout se recharge depuis la page Banques.

    Rien ne s'affiche ? L'entrée MIDI choisie à l'étape 5 n'est pas la bonne, ou le câble 2 est mal branché.

    INSERTmaintenir+VOICEpuisSPACE

astuces

Bon à savoir

Récupérer un son fait sur l'OSCar

Le plugin ne reçoit que ce qui est enregistré dans l'OSCar, pas le son en cours de réglage. Pour garder un son créé directement sur la machine :

  1. Sur l'OSCar, enregistre ton son dans une mémoire que tu peux écraser (STORE, comme d'habitude).
  2. Maintiens INSERT, appuie sur VOICE, puis sur SPACE : le plugin reçoit les 36 voix avec leurs valeurs exactes et affiche « Voix reçues (36) ».
  3. Dans le plugin, clique sur le numéro de cette mémoire : ton son s'affiche avec tous ses réglages.
  4. Page Banques : « Renommer » pour lui donner un nom, puis « Sauver voix… » (dossier Voices) ou « Enregistrer la banque… » pour garder les 36 voix.

Avec le patch CC dump, le plugin affiche déjà le son dès que tu choisis la mémoire sur l'OSCar, mais les potards sont à un cran près. Pour garder un son, préfère l'envoi INSERT, VOICE, SPACE.

Le son change en direct

Avec Live CC allumé, chaque potard part tout de suite vers l'OSCar. Ce n'est enregistré dans sa mémoire qu'avec « Envoyer au synthé », qui écrit les 36 voix d'un coup.

Le plugin suit l'OSCar

Choisis une voix sur l'OSCar : le plugin l'affiche telle qu'elle joue, mode Duo ou Arp compris. Il faut le patch CC dump (étape 6).

Essayer sans risque

Le Générateur joue chaque essai sur l'OSCar sans toucher à sa mémoire. « Retour à l'original » annule, « Garder » met le son dans la voix.

Arpège calé sur le DAW

Page Voix, bloc horloge midi : Sync sur Horloge MIDI et une Division (1/16, 1/8T…). Dans Réglages, active « Envoyer l'horloge MIDI du DAW à l'OSCar ».

Jouer avec un autre clavier

MIDI Thru (en bas de la fenêtre) fait passer les notes et le pitch bend de la piste vers l'OSCar. Laisse-le éteint si une autre piste envoie déjà des notes à l'OSCar.

Rien ne se perd

Chaque réception et chaque envoi est sauvegardé. « Sauver voix… » range une voix dans Voices, « Enregistrer la banque… » une banque dans Banks. Un double-clic les recharge.

Gare aux touches rouges

Sur la page Raccourcis Tauntek, les touches en rouge (sons d'usine, B, C, zones de sauvegarde) remplacent les 36 voix de l'OSCar. Enregistre une banque avant.

Pourquoi le plugin ouvre ses ports

Live ne laisse pas sortir le SysEx d'un plugin. OSCar Editor parle donc à l'OSCar par ses propres ports MIDI, choisis dans Réglages.
