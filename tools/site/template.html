installation

[[fr]]Installer et brancher, pas à pas[[en]]Install and connect, step by step[[/]]

[[fr]]Compte un quart d'heure la première fois. Les versions suivantes s'installent depuis le plugin, sans refaire ces étapes.[[en]]Allow fifteen minutes the first time. Later versions install from within the plug-in, without these steps.[[/]]

  1. 1

    [[fr]]Ouvrir l'image disque et glisser les fichiers[[en]]Open the disk image and drag the files[[/]]

    [[fr]]Double-clique sur OSCar-Editor-mac.dmg. Dans la fenêtre, glisse chaque fichier sur le dossier en face. macOS peut te demander ton mot de passe.[[en]]Double-click OSCar-Editor-mac.dmg. In its window, drag each file onto the folder opposite. macOS may ask for your password.[[/]]

    [[fr]]Logic Pro n'utilise que l'AU ; le VST3 sert aux autres logiciels, l'application marche sans DAW. Déjà installé ? Pas besoin du DMG : le plugin se met à jour lui-même.[[en]]Logic Pro only uses the AU; the VST3 is for other hosts, and the app works without a DAW. Already installed? No need for the disk image: the plug-in updates itself.[[/]]

  2. 2

    [[fr]]Débloquer le plugin, une seule fois[[en]]Unblock the plug-in, once[[/]]

    [[fr]]Le plugin n'est pas notarisé par Apple : tant qu'il n'est pas débloqué, macOS empêche Logic de le charger. Ouvre Terminal (⌘ Espace, tape « Terminal », Entrée), colle ce texte et appuie sur Entrée. Terminal demande le mot de passe de ta session : rien ne s'affiche pendant la frappe, c'est normal.[[en]]The plug-in isn't notarized by Apple: until it's unblocked, macOS stops Logic from loading it. Open Terminal (⌘ Space, type "Terminal", Return), paste this text and press Return. Terminal asks for your Mac password: nothing shows while you type, that's normal.[[/]]

    [[fr]]La dernière ligne doit dire « AU VALIDATION SUCCEEDED. » : Logic Pro peut alors charger le plugin. « No such file » pour un format que tu n'as pas installé est normal. Les mises à jour faites depuis le plugin n'ont pas besoin de ce déblocage.[[en]]The last line should read "AU VALIDATION SUCCEEDED.": Logic Pro can then load the plug-in. "No such file" for a format you didn't install is normal. Updates made from within the plug-in don't need this.[[/]]

    Terminal
    sudo xattr -dr com.apple.quarantine \
  "/Library/Audio/Plug-Ins/Components/OSCar Editor.component" \
  "/Library/Audio/Plug-Ins/VST3/OSCar Editor.vst3" \
  "/Applications/OSCar Editor.app"; \
killall -9 AudioComponentRegistrar 2>/dev/null; \
auval -v aumu Oscr Otls | tail -n 1
  3. 3

    [[fr]]L'ouvrir dans Logic Pro[[en]]Open it in Logic Pro[[/]]

    [[fr]]Relance Logic Pro : il vérifie les nouveaux plugins au démarrage. Crée une piste d'instrument logiciel, clique sur le slot d'instrument et choisis OSCar Editor dans les instruments AU, rubrique OSCarTools.[[en]]Restart Logic Pro: it checks new plug-ins when it starts. Create a software instrument track, click the instrument slot and choose OSCar Editor in the AU instruments, under OSCarTools.[[/]]

    [[fr]]Il n'apparaît pas ? Logic Pro › Réglages › Gestionnaire de module : sélectionne OSCar Editor, puis « Réinitialiser et réanalyser la sélection ». Le plugin ne produit aucun son : il parle directement à l'OSCar par ton interface MIDI.[[en]]Not there? Logic Pro › Settings › Plug-in Manager: select OSCar Editor, then "Reset & Rescan Selection". The plug-in makes no sound: it talks straight to the OSCar through your MIDI interface.[[/]]

  4. 4

    [[fr]]Brancher l'OSCar et choisir les ports[[en]]Connect the OSCar and choose the ports[[/]]

    [[fr]]Un câble va toujours d'un OUT vers un IN. Puis, page Réglages du plugin : Sortie = la sortie de l'interface où arrive le câble 1, Entrée = l'entrée où arrive le câble 2, canal 1 sauf si ton OSCar est réglé autrement.[[en]]A cable always goes from an OUT to an IN. Then, on the plug-in's Setup page: Out = the interface output cable 1 is plugged into, In = the input cable 2 is plugged into, channel 1 unless your OSCar is set otherwise.[[/]]

    [[fr]]Avec un câble USB-MIDI tout-en-un, les fiches IN et OUT sont parfois étiquetées à l'envers : si rien ne passe, inverse-les. Le plugin retient tes ports.[[en]]With an all-in-one USB-MIDI cable, the IN and OUT plugs are sometimes labelled the other way round: if nothing gets through, swap them. The plug-in remembers your ports.[[/]]

    [[fr]]Deux réglages sur l'OSCar[[en]]Two settings on the OSCar[[/]]

    [[fr]]Program change, pour que l'OSCar passe sur la voix que tu cliques dans le plugin : maintiens SPACE (à gauche du clavier) et appuie sur la touche −9. La LED −9 s'allume.[[en]]Program change, so the OSCar switches to the voice you click in the plug-in: hold SPACE (left of the keyboard) and press key −9. The −9 LED lights up.[[/]]

    [[fr]]Patch CC dump, pour que le plugin suive les voix choisies sur l'OSCar : maintiens TUNE/TRANSPOSE et appuie sur la touche « Enable patch CC dump », la dernière touche noire de l'octave du milieu. Le voyant CC DUMP du plugin s'allume au prochain changement de voix.[[en]]Patch CC dump, so the plug-in follows the voices chosen on the OSCar: hold TUNE/TRANSPOSE and press the "Enable patch CC dump" key, the last black key of the middle octave. The plug-in's CC DUMP light comes on at the next voice change.[[/]]

[[fr]]astuces[[en]]tips[[/]]

[[fr]]Bon à savoir[[en]]Good to know[[/]]

[[fr]]Récupérer un son fait sur l'OSCar[[en]]Keep a sound made on the OSCar[[/]]

[[fr]]Le plugin ne reçoit que ce qui est enregistré dans l'OSCar, pas le son en cours de réglage. Pour garder un son créé directement sur la machine :[[en]]The plug-in only receives what is stored in the OSCar, not the sound you are tweaking. To keep a sound made on the synth itself:[[/]]

  1. [[fr]]Sur l'OSCar, enregistre ton son dans une mémoire que tu peux écraser (STORE, comme d'habitude).[[en]]On the OSCar, store your sound in a memory you can overwrite (STORE, as usual).[[/]]
  2. [[fr]]Maintiens INSERT, appuie sur VOICE, puis sur SPACE : le plugin reçoit les 36 voix avec leurs valeurs exactes et affiche « Voix reçues (36) ».[[en]]Hold INSERT, press VOICE, then SPACE: the plug-in receives the 36 voices with their exact values and shows "Voices received (36)".[[/]]
  3. [[fr]]Dans le plugin, clique sur le numéro de cette mémoire : ton son s'affiche avec tous ses réglages.[[en]]In the plug-in, click that memory's number: your sound shows up with all its settings.[[/]]
  4. [[fr]]Page Banques : « Renommer » pour lui donner un nom, puis « Sauver voix… » (dossier Voices) ou « Enregistrer la banque… » pour garder les 36 voix.[[en]]Banks page: "Rename" to give it a name, then "Save voice…" (Voices folder) or "Save bank as…" to keep all 36 voices.[[/]]

[[fr]]Avec le patch CC dump, le plugin affiche déjà le son dès que tu choisis la mémoire sur l'OSCar, mais les potards sont à un cran près. Pour garder un son, préfère l'envoi INSERT, VOICE, SPACE.[[en]]With the patch CC dump on, the plug-in already shows the sound when you pick the memory on the OSCar, but knobs are within one step. To keep a sound, use INSERT, VOICE, SPACE.[[/]]

[[fr]]Le son change en direct[[en]]The sound changes live[[/]]

[[fr]]Avec Live CC allumé, chaque potard part tout de suite vers l'OSCar. Ce n'est enregistré dans sa mémoire qu'avec « Envoyer au synthé », qui écrit les 36 voix d'un coup.[[en]]With Live CC on, every knob goes straight to the OSCar. It's only stored in its memory with "Send voices to synth", which writes all 36 voices at once.[[/]]

[[fr]]Le plugin suit l'OSCar[[en]]The plug-in follows the OSCar[[/]]

[[fr]]Choisis une voix sur l'OSCar : le plugin l'affiche telle qu'elle joue, mode Duo ou Arp compris. Il faut le patch CC dump (étape 5).[[en]]Pick a voice on the OSCar: the plug-in shows it as it plays, Duo or Arp mode included. This needs the patch CC dump (step 5).[[/]]

[[fr]]Essayer sans risque[[en]]Try things safely[[/]]

[[fr]]Le Générateur joue chaque essai sur l'OSCar sans toucher à sa mémoire. « Retour à l'original » annule, « Garder » met le son dans la voix.[[en]]The Generator plays every try on the OSCar without touching its memory. "Back to original" undoes, "Keep" puts the sound in the voice.[[/]]

[[fr]]Arpège calé sur Logic[[en]]Arpeggiator in time with Logic[[/]]

[[fr]]Page Voix, bloc horloge midi : tourne Sync sur MIDI et choisis une Division (1/16, 1/8T…). Puis, au choix, « Envoyer l'horloge MIDI du DAW à l'OSCar » dans Réglages, ou l'horloge de Logic (Fichier › Réglages du projet › Synchronisation › MIDI, Destination = le port de l'OSCar, case Horloge). Pas les deux.[[en]]Voice page, midi clock block: turn Sync to MIDI and pick a Division (1/16, 1/8T…). Then either "Send the DAW's MIDI clock to the OSCar" in Setup, or Logic's own clock (File › Project Settings › Synchronization › MIDI, Destination = the OSCar's port, Clock box). Not both.[[/]]

[[fr]]Jouer l'OSCar depuis Logic[[en]]Play the OSCar from Logic[[/]]

[[fr]]Sélectionne la piste OSCar Editor et allume MIDI Thru (en bas de la fenêtre) : ton clavier maître et les régions MIDI de la piste jouent l'OSCar. Laisse-le éteint si tu joues déjà l'OSCar avec le module External Instrument de Logic.[[en]]Select the OSCar Editor track and turn on MIDI Thru (bottom of the window): your controller keyboard and the track's MIDI regions play the OSCar. Leave it off if you already play the OSCar through Logic's External Instrument plug-in.[[/]]

[[fr]]Rien ne se perd[[en]]Nothing gets lost[[/]]

[[fr]]Chaque réception et chaque envoi est sauvegardé. « Sauver voix… » range une voix dans Voices, « Enregistrer la banque… » une banque dans Banks. Un double-clic les recharge.[[en]]Every receive and every send is backed up. "Save voice…" files a voice in Voices, "Save bank as…" a bank in Banks. A double-click loads them back.[[/]]

[[fr]]Gare aux touches rouges[[en]]Mind the red keys[[/]]

[[fr]]Sur la page Raccourcis Tauntek, les touches en rouge (sons d'usine, B, C, zones de sauvegarde) remplacent les 36 voix de l'OSCar. Enregistre une banque avant.[[en]]On the Tauntek keys page, the red keys (factory, B, C sounds, save areas) replace the OSCar's 36 voices. Save a bank first.[[/]]

[[fr]]Rien à router dans Logic[[en]]Nothing to route in Logic[[/]]

[[fr]]Dans Logic, un instrument AU ne peut pas envoyer de MIDI vers une interface. OSCar Editor parle donc à l'OSCar par ses propres ports MIDI, choisis dans Réglages.[[en]]In Logic, an AU instrument can't send MIDI to an interface. So OSCar Editor talks to the OSCar through its own MIDI ports, chosen in Setup.[[/]]
